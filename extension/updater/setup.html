Cài NOTA Updater một lần

Sau bước này, các phiên bản sau chỉ cần bấm Update ngay. Updater tự tải đúng GitHub Release, kiểm tra SHA256, thay file và reload extension.
  1. Mở thư mục bản extension đang được Load unpacked.
  2. Double-click file Install-NOTA-Updater.cmd.
  3. Chờ cửa sổ báo Hoàn tất, rồi đóng và mở lại popup extension.

Không cần quyền Administrator. Bộ cài tự tìm ID của thư mục đang được Load unpacked và native host chỉ nhận lệnh từ đúng extension đó.
