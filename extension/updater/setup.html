Set up NOTA Updater once

After setup, click Update now for future versions. The updater downloads the GitHub release, verifies SHA256, replaces the files, and reloads the extension. Reload your DMS tab afterward.

Windows

  1. Open the extension folder you selected with Load unpacked.
  2. Double-click file Install-NOTA-Updater.cmd.
  3. If asked for an Extension ID, open chrome://extensions, enable Developer mode, and paste the ID shown below NOTA Labeling Organizer.
  4. Wait for Done, then close and reopen the extension popup.

macOS / MacBook

  1. Open the extension folder you selected with Load unpacked. Use the GitHub release ZIP, which includes the macOS updater binary.
  2. Right-click Install-NOTA-Updater.command, select Open, and select Open again if macOS asks.
  3. Wait for Terminal to confirm installation, press Enter, then close and reopen the extension popup.

No administrator access is needed. The installer detects the ID associated with this unpacked folder; the native host accepts requests only from that extension.
