NOTA Labeling Organizer

Enabled

Current version:

  1. Open Labeling, search a part (for example ciga or phone), then expand a clip such as #01.
  2. A / D: previous / next visible frame. Shift+A / Shift+D: move 10 frames. Space: play / pause the visible list.
  3. F: toggle Done / In progress. Each clip also has status buttons that update every frame in it.
  4. N: create a box with two corner clicks, or draw a seatbelt polygon. M: draw an erase region; close it with a right-click or a click on its first point. Esc: exit.
  5. Ctrl+B: repeat an edit across previous / next frames. Enter a count or end. The source frame is excluded and Done targets are skipped.
  6. Copy boxes: copying a selected box replaces matching boxes and keeps other objects; a missing match adds a box. Copying all boxes replaces the target box list.
  7. Body / hand / eye box: X deletes all boxes; 1 / 2 delete the leftmost / rightmost box. C copies all boxes from the previously viewed frame. Shift+X / Shift+C also advance one frame.
  8. Body / hand / eye box: Ctrl+C / Ctrl+V copy / paste, V marks target frames, Ctrl+B repeats the latest operation, and Z undoes it, including an entire batch.
  9. Body edge: double-click an edge handle, then drag it. Ctrl+B applies the blue edge's exact position to matching boxes, preserving the other three edges. A missing match adds the edited box.
  10. Seatbelt SAM3: left-click (+), right-click (−). When the green preview is ready, press R or Enter to add it; Shift+Enter subtracts it. Ctrl+B defaults to the latest change only.
  11. Seatbelt Z: undo the last polygon point or the latest mask edit on this frame. Esc / Cancel clears pending edits; saved edits require Undo.
  12. Eye 15pt: drag inside the dashed box to move; Ctrl + drag to rotate; drag edge / corner handles to resize. K toggles eye points or seatbelt mask visibility.
  13. Reopen Done frames: on labels other than body/hand/eye boxes, select Done frames with V, then Ctrl+B → Set In progress. Existing annotations stay.

On macOS, Cmd+B and Cmd+C/V also work. Shortcuts apply outside text fields. Search and grouping only change the interface; edits and status actions save to DMS.
